# Babysitter Booking Platform

## Project Structure

- **Frontend**: React + Vite (this repository)
- **Backend**: ASP.NET Core API + SQL Server
  - Repository: https://github.com/abdulli23309-ops/babysitter-booking-platform-api
  
## Features
- Parent dashboard with child profile management
- Babysitter matching and job management
- Real-time notifications
- YamNet ML for cry detection
- Rating and review system

## Setup

### Frontend
```bash
npm install
npm run dev
```

### Backend
[[Link to backend repo for instructions]](https://github.com/abdulli23309-ops/babysitter-booking-platform-api)
